# Fire in da Hole

A playful 3D browser game with flick-to-throw controls, moving targets, and cartoon sound effects.

**[Play in your browser](https://crapthings.github.io/fireindahole/)**

## Make your own with run3d

**[run3d](https://github.com/crapthings/run3d)** is my JavaScript starter for 3D games and interactive experiments, with Vite, React Three Fiber, and tools for animation and physics. Start with an editable scene and make it your own.
